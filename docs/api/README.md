# API contract

`openapi.yaml` lives here and is the source of truth for every endpoint.

The first version covers `GET /healthz` (LAP-20). The Tier 0 endpoints, vibe search
(UC-01), venue detail (UC-02), and trip create and read (UC-03), are added spec first by
their own tickets, following `docs/playbooks/change-the-api.md`.
